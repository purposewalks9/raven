# Changelog

All notable changes to the Raven Language extension will be documented in this file.

## [0.0.1] - 2026-07-26

### Added
- Initial release of Raven Language extension
- Diagnostics support with real-time type checking
- Hover information for symbols
- Go to definition navigation
- Find references functionality
- Syntax highlighting for `.rv` files
- Language configuration with comment and bracket handling

### Fixed
- Workspace configuration for monorepo setup
- Language server bundling in extension package
- Build order dependencies between compiler, language server, and extension
