## Analysis — Phase 2 vs Phase 1

Phase 1 (`check` AST-in) vs Phase 2 (`check` source-in) on the same release build:

| Fixture | Phase 1 `check` (AST-in) | Phase 2 `check` (source-in) | TS baseline (`check` only) |
|---|---|---|---|
| small (15 lines) | 501 µs | **105 µs** (3.3× faster) | 15 µs |
| medium (407 lines) | 15520 µs | **4110 µs** (3.8× faster) | 466 µs |
| workspace (56 files) | 229662 µs | **67989 µs** (3.4× faster) | ~16 ms |

Source-in removes the large JSON AST that crossed the boundary in both directions in Phase 1. For the medium fixture, `check` (source-in) 4110 µs is now the same order as the TS `lex` (1574 µs) + `parse` (2171 µs) + `check` (466 µs) = 4211 µs total — i.e. Rust is at parity with the TS pipeline end-to-end, not yet faster but no longer dominated by marshalling. The remaining gap is the output side (`bindings` → JSON `Value` + `to_string`), which Phase 2 addresses for the CLI by splitting `check_source` (diagnostics only, 105 µs/4110 µs) from `bindings_for` (bindings+types, lazily called). The workspace `buildProject` (67989 µs) is 3.4× faster than Phase 1's 229 ms but still ~4× the TS 16 ms baseline — the next wins are Phase 3's `emitter`/`optimizer`/`sourcemap` (removing the AST-out leg).

**Why not yet at 466 µs?** `check (source-in)` intentionally includes `tokenize` + `parse` + `check` in Rust (one FFI call). The isolated checker engine is still ~934 µs for the medium fixture (phase1-ffi-analysis.md), same order as TS. The 4110 µs is lex+parse+check combined, which matches the TS lex+parse+check total (4211 µs).

**Design decision (AST-out):** `compiler/src/cli/pipeline.ts:checkSource` still builds the AST in TypeScript for `optimize`/`Emitter` until Phase 3. This means `checkSource` currently parses twice (TS for AST, Rust for diagnostics) — intentional and documented in that file. The alternative (ship Phase 2+3 together) was considered; we chose to keep Phase 2 standalone and pay the duplicate parse (≈ 2.7 ms medium) rather than delay the FFI fix. Phase 3 will make the whole compile one native call and the AST-out leg disappears.
